Суррогаты для МКЭ02 / 12 · Проблема

Один расчёт терпим. Сотни расчётов - уже проблема

Один расчёт ANSYS занимает секунды или минуты. Параметрическое исследование и оптимизация требуют сотен запусков, поэтому перебор растягивается на часы.

12,9 с - средний расчёт ANSYS в контрольном замере.
0,00486 с - прогноз обученного GPR.
×2653 - измеренное ускорение одного отклика.
Суррогат закрывает вопрос скорости. Открытым остаётся вопрос - какую именно модель брать для конкретного физического отклика.
Суррогаты для МКЭ03 / 12 · Цель и задачи

Цель и задачи проекта

Цель

Сократить число дорогих конечно-элементных расчётов с помощью ML-суррогата и определить, какую регрессионную модель выбирать для разных типов физического отклика.

Критерий успеха: быстрый отклик за миллисекунды, воспроизводимая оценка качества и обязательная проверка итогового решения полным расчётом.
Задачи
01
Сформировать собственные выборки на задачах с разной гладкостью отклика.
02
Сравнить 8 моделей по единой схеме кросс-валидации и настроить ансамбли деревьев.
03
Найти границу, на которой лидер меняется между GPR и градиентным бустингом.
04
Оформить результат как открытый воспроизводимый инструмент для инженера.

Суррогаты для МКЭ07 / 12 · Находка

Находка: лидер меняется по гладкости

R² по k-блочной кросс-валидации, 5 блоков × 3 сида. Деревья настроены Optuna, GPR самонастраивается по правдоподобию ядра - сравнение честное.

Что это меняет на практике
Тип данных сам по себе не определяет лидера. На малых выборках решающим фактором оказалась гладкость физического отклика: GPR лидирует на гладких задачах, а бустинг выходит вперёд при резкой нелинейности.
